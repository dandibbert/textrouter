# Vendor documentation

`vendor_help/` is TextSoap's **own help book**, converted from the HTML shipped
inside the app to Markdown. It is the single most useful thing in this pack:
for most cleaners it states the exact transform, and for the action editor it
documents the parameters.

Most relevant pages:

- `vendor_help/cleaner_descriptions.md` — what the common cleaners do
- `vendor_help/my_cleaner_actions.md` — **every action and its parameters**
- `vendor_help/regex_syntax.md` — the regex dialect
- `vendor_help/clipboard_workspace.md` — the Clipboard Space workflow
- `vendor_help/batch_cleaning.md` — batch file cleaning
- `vendor_help/custom_cleaner_tutorial_1..4.md` — building chains, lists, conditionals
- `vendor_help/date_actions.md`, `html_actions.md`, `plist_actions.md` — action families
