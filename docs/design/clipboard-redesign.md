# 剪贴板空间重设计（新粗野风格）· 实现规格

> 给实现者（人或 coding agent）看的交接文档。视觉和交互以 `reference/BrutalPro.dc.html` 为准，
> 组件状态以 `reference/States.dc.html` 为准，动效以 `reference/Motion.dc.html` 为准。
> 这三个文件是设计原型的源码（HTML + CSS + JS），不能直接用浏览器打开运行，但里面的颜色、尺寸、
> 动画参数和交互逻辑都是精确值，遇到本文没写清楚的细节，直接去原型源码里找。

## 0. 范围

- **只改剪贴板空间这一个窗口**（现在的 `gui/clipboard.go`），把查找替换（现在的 `gui/find.go`）
  做成这个窗口右栏的第二个标签页。侧边栏的其他页面这次不动，以后沿用本文的设计令牌（tokens）。
- **不改 `engine/`**。原型里用 JS 写的清理器、diff、正则解释只是演示用的，实现时一律调用现有引擎：

  | 原型里的 JS | 用引擎里的 |
  |---|---|
  | `ops()` 清理器 | `engine.CleanerByName` / `resolveAction`（已有） |
  | `diff()` | `engine.Diff` / `engine.DiffStats` |
  | `runFind()` | `engine.FindOptions.FindAll`（含 `Match.Groups`） |
  | 跳过部分匹配后替换 | `engine.ApplyMatches(text, 被勾选的 matches)` |
  | `explain()` / `explainRep()` | `engine.ExplainPattern` / `engine.ExplainTemplate` |
  | 模式菜单的内置模式 | `engine.Presets()`（可按 §5.3 增补） |
  | 步骤记录 | `App.history` / `App.future`（已有撤销、重做栈） |

- 现有功能（⌘K 动作面板、⌘↩ 复制并收起、全局快捷键、固定清理器和动作链）全部保留。

## 1. 设计令牌

先把它们定义成一个 Go 文件（建议 `gui/theme_brutal.go`），所有组件只引用令牌，不写裸色值。

### 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `Ground` | `#F3EFE4` | 窗口底色 |
| `Paper` | `#FFFFFF` | 正文卡片、输入框、菜单 |
| `Ink` | `#000000` | 文字、所有描边、所有硬阴影 |
| `Muted` | `#3F3F3F` | 次要文字（在 Ground 和 Paper 上都过 4.5:1） |
| `Faint` | `#7A7A7A` | 占位文字、禁用、被撤销的步骤 |
| `Accent` | `#FFD23F` | 主按钮、悬停行、当前项、滚动条滑块 |
| `AccentHover` | `#FFDB5E` | 主按钮悬停 |
| `AccentSoft` | `#FFF1B8` | 胶囊悬停、选中行、菜单里已选模式 |
| `AccentWash` | `#FFF7D6` | 当前匹配所在行的整行底色 |
| `Focus` | `#3A5BFF` | 键盘聚焦环、跳转波纹（刻意和黄色区分） |
| `Del` | `#FFB4A3` | 将删除的文字底色（配 2px 黑删除线） |
| `Ins` | `#A6F0BF` | 将新增的文字底色 |
| `Hit` | `#FFE47A` | 只匹配不替换（配底部 2px 黑线） |
| `GutterBg` | `#FBF7EC` | 行号栏底色 |
| `MarkDel` / `MarkAdd` | `#FF6B4A` / `#2FBF71` | 行号栏和滚动条上的改动标记 |
| `Tile*` | 空格类 `#8FB6FF`，引号类 `#FF9F6B`，行/段落类 `#7EE0B5`，大小写类 `#F7A6E0`，动作链 `#FFD23F` | 清理器图标底色 |

### 形状

- **描边一律 2px `Ink`**。键帽是例外：1.5px，底边 3px。
- **阴影一律硬边**：模糊 0，向右下偏移，颜色 `Ink`。小控件 3px，卡片 5px，浮层（菜单）6px。
  对应 MyGo 的 `Element.Shadow(x, y, 0, 0, Ink)`。
- 圆角：按钮、输入框、行 6px；分段控件外框 8px，里面的滑块 5px；胶囊和数字徽标 999px；清理器图标 5px。

### 字体

- 界面用 Space Grotesk（400/500/700），等宽用 Space Mono（400/700），中文回退到 Noto Sans SC。
  三个都是 OFL 授权，用 `ui.RegisterFont` 打包进 app。如果不想打包，就回退到 SF Pro / SF Mono / 苹方，
  其余规格照旧。
- 字号：正文编辑区 13px，行高 25px；列表 13px；按钮 12.5–13px；分组小标题 11px 粗体、全大写、
  字距 0.08em；徽标和行号 11px 等宽。

## 3. 正文区

**用 MyGo 自带的代码编辑器 `ui/editor` 实现**，下面的功能它基本都有，不要自己从零写：

| 需求 | `editor.State` 里对应的字段 |
|---|---|
| 行号，可开关 | `LineNumbers`；底部 `#` 按钮切换 |
| 点行号选中整行 | `OnGutterClick` |
| 显示空格、制表符、换行 | `Whitespace`；底部 `¶` 按钮切换 |
| 长行自动折行 | `SoftWrap`（折行只在第一截标行号） |
| 预览时标出删除和新增 | 由 `engine.Diff` 生成区间，交给 `Highlighter` 着色 |
| 行号栏的改动竖条 | `GutterMarks`（或用 `DiffBase`，如果它的样式能调到下面这样） |
| 颜色 | `Theme` |

### 行号栏

- 宽度按最大行号的位数算：`位数 × 7 + 18` px，两位数时 32px，至少按两位数算。右侧 2px 黑线。
- 行号右对齐，右边留 7px，和正文间隔 14px，默认颜色 `#9A9A9A`，悬停变 `Ink`。
- 改动竖条：宽 3px，贴最左边（left 3px），上下各缩 5px。颜色：有删除 → `MarkDel`，只有新增 → `MarkAdd`，
  只匹配 → `Ink`。
- 当前匹配所在行：行号格变 `Accent` 底、粗体、右侧补 2px 黑线；整行铺 `AccentWash`。
- 点行号选中的整行：铺 `AccentSoft`，再点一次取消；文本变化后自动取消。

### 滚动条（需要自绘）

MyGo 的主题只能设置滑块颜色和宽度（`Theme.Scrollbar`、`ScrollbarWidth`），做不出下面的描边和轨道线。
所以要么关掉自带的，自己画一个覆盖层（可以用 `ScrollbarInsets` 留出位置，用 `Painter` 画）；
要么先用主题色 `Accent`、宽度 10 顶上，后面再换。目标样式：

- 宽 16px。轨道是居中的 2px 黑竖线。
- 滑块：`Accent` 底色的药丸，2px 黑描边，左右各缩 3px，最小高度 44px。
  悬停时底色变 `#FFB800`，拖动时变 `Ink`。
- 所有滚动区域统一用这个：正文、清理器列表、匹配列表、模式菜单、规则解释框。

### 滚动条旁的刻度

在滚动条左侧放一列 8px 宽的刻度，不接收鼠标点击。纵向位置 = `(行号 − 1) / (总行数 − 1)`。

- 查找替换时：每处匹配画一个 6×3 的黑刻度；当前这处画一个 12×7 的 `Accent` 方块，带 2px 黑边，
  跳转时用 300ms 减速曲线滑到新位置。
- 清理预览时：每个有改动的行画一个 6×4 的 `MarkDel` 刻度。
- 刻度出现时依次展开（每个延迟 15ms，最多到 300ms）。

### 正文里的标记

| 状态 | 样式 |
|---|---|
| 将删除 | `Del` 底 + 2px 黑删除线。删掉的空格显示为 `·`，换行显示为 `⏎`，制表符显示为 `→` |
| 将新增 | `Ins` 底 |
| 只匹配（替换框为空、或在模式菜单里预览） | `Hit` 底 + 底部 2px 黑线 |
| 当前这处 | 再加 2px 黑描边，外扩 1px |
| 被勾掉、不替换 | 文字变 `Faint` + 底部 2px 浅灰线 |
| 选中文字 | `Accent` 底 |
| 光标 | 2px 黑竖线，闪烁周期 1.06s |

## 4. 右栏

顶部是分段控件 `[清理 ⌘1 | 查找替换 ⌘F]`：白底，2px 黑框，3px 硬阴影，里面有一个黄色滑块，切换时弹性滑动（见 §6）。

### 4.1 清理

- **搜索框**：输入时实时筛选全部清理器和动作链，右侧显示 `⌘K` 键帽。
  搜不到时显示一个虚线框：「没有叫「X」的动作」，下面一个按钮「用「X」新建查找替换 →」，
  点了就切到查找替换页，并把 X 作为文字（非正则）填进查找框。
- **分组**：「常用」（固定的清理器）和「动作链」，分组小标题右侧写一句说明。
- **每一行**：清理器图标（26px，按类别着色，2px 黑框）+ 名称 + 改动徽标 + 星标。
  - 改动徽标是这个清理器**对当前文本**实际会改多少：行数变少时显示「−N 行」，否则显示「N 处」
    （N 是 `engine.Diff` 结果里连续改动块的数量）。不会改动的显示灰色「无变化」，名称也变灰。
    这个数要缓存：文本没变就不重算。
  - **悬停 = 预览**：正文立刻按 §3 的样式显示这个清理器会改什么，状态栏显示
    `[预览] 名称 改动量 · 删/增图例 · 点击应用 · 移开即恢复`。鼠标离开整个列表时恢复原样。
  - **点击 = 应用**：压入历史栈，然后播放「应用」动效（§6）。
  - 悬停时行变成 `Accent` 底 + 2px 黑框 + 向左上抬起 2px + 3px 硬阴影，
    徽标变成白底黑框，星标旋转着出现。点星标加入或移出「常用」。
- 底部：「全部 189 个清理器 →」链接，右边一行提示「悬停后点 ☆ 加入常用」。

### 4.2 查找替换

从上到下依次是：

1. **查找 / 替换输入框**：上下两行合在一个框里，中间 2px 黑线分隔。
   - 查找行最右边是「模式 ▾」按钮。套用了模式时，查找框里出现黑底黄字的模式标签（如「价格 ×」），
     整个框的阴影变成黄色。
   - 替换框为空时，占位文字是「留空 = 删除匹配」。
2. **开关行**：`[.* 正则] [Aa] [解释]` 三个胶囊开关；右侧是 `[↑] 3 / 12 [↓]`，计数变化时数字向上翻。
3. **出错提示**：正则写错时，显示 `Del` 底、黑框的提示框，出现时左右抖一下，同时禁用两个替换按钮。
4. **捕获组**：「第 N 处的组：`$0` 值 `$1` 值 …」，最多显示 5 个，值超过 18 个字截断。
   点一个组就把 `$n` 追加到替换框。只在正则模式下显示。
5. **规则解释**：默认关闭，点「解释」开关才显示。用 `ExplainPattern` + `ExplainTemplate`，
   限高 132px、可滚动、虚线框。每行是一个记号（查找部分浅黄底，替换部分绿底，无效记号红底）+ 中文解释。
6. **匹配列表**：小标题右侧注明「勾掉的不替换」。每条匹配占一行，高 32px：
   `[☑] L8  …前 12 字 [匹配内容] 后面一段…  [→ 替换结果]`
   - 整行一行显示，超长用省略号截断：匹配内容最多 26 字，替换结果最多 92px 宽。
   - 点一行 = 设为当前，正文和列表都平滑滚动，让这一条位于中间。当前行是 `Accent` 底 + 黑框。
   - 复选框是自绘的：18px 方框，2px 黑边；勾上是黄底黑勾，勾的出现带弹性缩放。
     勾掉后这一条的替换结果半透明并加删除线。
   - 最多渲染 300 条（用虚拟列表更好）。没有匹配时显示虚线框，里面给出建议按钮：
     「关掉区分大小写」（仅在开着时出现）、「改用正则」（仅在没开时出现）、「从模式里挑一个」。
7. **按钮行**：`[替换这一处]`（⌥⌘↩，替换后当前位置自动指向下一处）、
   `[全部替换 · N 处]`（主按钮，N 已排除勾掉的）、`[⋯]`（加入批量规则 / 存为动作链步骤）。

**模式菜单**（点「模式 ▾」打开，浮在输入框下方，白底，2px 黑框，6px 硬阴影）：

- 分「内置」和「我的模式」两组。每项显示：名称 + 简短说明 / 规则本身（等宽、灰色）/ 在当前文本里的匹配数。
- 悬停一项，正文立即按「只匹配」样式高亮它会匹配到的内容，状态栏显示 `[预览] 模式「X」 N 处匹配`。
- 点击 = 套用：先记下当前的「查找 / 替换 / 正则」三项，再填入这个模式和它配套的替换串，然后关闭菜单。
- 已套用的模式前面显示 ✓。**再点一次**、或者点查找框里模式标签上的 ×，就取消套用并恢复刚才记下的三项。
  手动修改查找框，模式标签也会自动消失。
- 底部按钮「＋ 把当前规则存为我的模式」。

内置模式及配套替换串（可增补到 `engine.Presets()`）：数字 `\d+`；价格 `(\d+)元` → `¥$1`；
日期 `(\d{4})-(\d{2})-(\d{2})` → `$1年$2月$3日`；手机号 `1[3-9]\d{9}`；邮箱；网址 `https?://\S+`；
连续空格 ` {2,}` → 一个空格；中英文相邻 `([一-鿿])([A-Za-z])` → `$1 $2`。

## 5. 标题栏和全局反馈

- **步骤记录**：放在标题栏中间，用历史栈渲染成 `原文 → 步骤1 → [当前]`。
  - 当前步骤是 `Accent` 底 + 2px 黑框；之前的步骤是灰字；撤销掉的步骤是浅灰 + 删除线，点它可以重做到那一步。
  - 点任意一步都会跳回那一步（不删历史，所以可以再前进）。
  - 有 2 步及以上时，显示「存为动作链」按钮：把这几步存成一条新动作链，然后弹出提示条。
- **撤销 / 重做**：无边框的图标按钮，悬停时出现白底黑框。没有可撤销或可重做的步骤时禁用（透明度 0.3）。
- **复制并完成**：主按钮。点击后，按钮里画出一个对勾并显示「已复制」，同时底部弹出提示条：
  「已复制到剪贴板 · 窗口即将收起，回到 Safari 直接 ⌘V」。之后按现有逻辑收起窗口。
- **提示条（toast）**：黑底白字，右下 4px 黄色硬阴影，左边一个黄色圆形对勾。
  从窗口底部中间弹上来，停 2 秒后下沉消失。
- **悬停提示（tooltip）**：所有图标按钮都要有。黑底白字 11.5px，鼠标停 0.45 秒才出现，避免扫过时闪烁。
- **键帽**：快捷键提示一律画成键帽：1.5px 黑框，底边 3px，等宽 10px 字。

## 6. 动效

全部用 MyGo 的 `Element.Transition`、`AnimateTo` 和 `Animation` 实现。`ReduceMotion` MyGo 会自动处理，
不需要额外写判断。

三条曲线：

```go
var (
    EaseSpring = ui.CubicBezier(.34, 1.56, .64, 1) // 弹性：按压、弹入、滑块
    EaseOut    = ui.CubicBezier(.22, 1, .36, 1)    // 减速：进入、展开、滚动
    EaseIn     = ui.CubicBezier(.4, 0, 1, 1)       // 加速：退出、收起
)
```

| 动效 | 触发 | 做什么 | 时长 / 曲线 |
|---|---|---|---|
| 悬停预览 | 悬停清理器或模式 | 新增的底色从左往右刷满；删除的底色和删除线从透明淡入 | 320ms 减速 |
| 点击应用 | 点清理器 / 替换 | 删掉的文字原地收拢消失（透明度和宽度都到 0）；新增的先闪一下 2px 黑框，然后在 1.3s 内底色褪掉 | 500ms + 1.3s |
| 跳到某处匹配 | ↑↓、点列表、⌘G | 黑描边移到新位置，并向外扩散一圈 `Focus` 色的波纹（0 → 12px，透明度 0.7 → 0）；正文和列表平滑滚动；刻度方块滑过去 | 550ms 减速 |
| 列表行悬停 | 鼠标进入行 | 抬起 2px，出现 3px 硬阴影，底色变黄；星标从缩小 50%、旋转 −30° 恢复原样 | 160ms 弹性 |
| 按钮按下 / 松开 | 鼠标按下 | 按下时移动 3px、阴影归零（60ms）；松开时回弹到抬起 1px（160ms 弹性）。悬停时抬起 1px、阴影变 4px | 60ms / 160ms |
| 切换标签 | 点标签或 ⌘1、⌘F | 黄色滑块滑过去；下面的面板从同一个方向滑入 10px 并淡入 | 340ms 弹性 / 300ms 减速 |
| 列表首次出现 | 进入标签页 | 每行从下方 6px 淡入，依次延迟 24ms（用 `Animation.Delay`） | 340ms 减速 |
| 模式菜单 | 打开 / 关闭 | 以右上角为原点，从 95% 放大并下移 8px 展开，菜单项依次延迟 22ms；关闭时缩到 97% 并淡出 | 240ms 弹性 / 140ms 加速 |
| 计数变化 | 计数、替换数变化 | 新数字从下方 60% 处向上翻入 | 220ms 减速 |
| 新增步骤 | 历史栈压入一步 | 新的步骤标签从 60% 弹到 100% | 280ms 弹性 |
| 模式标签出现 | 套用模式 | 同上，弹入 | 280ms 弹性 |
| 规则解释展开 | 打开「解释」 | 高度从 0 展开，每行依次延迟 30ms 淡入 | 280ms 减速 |
| 出错 | 正则写错 | 出错框左右抖动 −5/5/−3/2 px | 380ms |
| 复选框 | 勾选 / 取消 | 勾从 0 缩放到 1 | 200ms 弹性 |
| 复制成功 | 点复制 | 对勾路径逐渐画出；提示条弹上来，停 2s 后下沉 | 340ms；340ms 弹性 / 220ms 加速 |
| 改动竖条 | 预览出现 | 竖条从高度 0 展开 | 300ms 减速 |

规则：任何动画进行到一半，都能被下一次操作打断并接着过渡（用弹簧或 `AnimateTo` 天然满足）。
悬停预览在行和行之间移动时，每次都要重新播放刷出效果。
